# Glosarium Singkat (urut abjad)

| Istilah | Arti sederhana |
|---|---|
| **α (alpha) = 0.05** | Batas risiko salah yang kita terima (5%). Dipakai sebagai patokan p-value. |
| **ANOVA** | Uji untuk membandingkan rata-rata **3 kelompok atau lebih** sekaligus. |
| **Adjusted R²** | R² yang disesuaikan jumlah prediktor; tidak naik hanya karena menambah variabel tak berguna. |
| **Binomial** | Model peluang jumlah "sukses" dari n percobaan identik dengan 2 hasil. |
| **Chi-Square (χ²)** | Uji hubungan antara 2 variabel kategori. |
| **CI (Confidence Interval)** | Rentang yang kemungkinan besar memuat nilai populasi sebenarnya. |
| **Cohen's d / eta² / Cramér's V** | Ukuran **besar** efek (bukan hanya ada/tidaknya). |
| **Dummy variable** | Variabel 0/1 untuk memasukkan kategori ke regresi. |
| **Frekuensi observasi / ekspektasi** | Hitungan nyata di data / hitungan yang diharapkan jika H0 benar. |
| **Gagal tolak H0** | Bukti belum cukup untuk menyatakan ada beda. (Bukan "H0 benar".) |
| **H0 / H1** | Hipotesis nol (tidak ada beda/hubungan) / hipotesis alternatif (ada). |
| **Homoskedastisitas** | Sebaran residual sama lebar di semua nilai prediksi. |
| **Imputasi** | Mengisi data kosong dengan nilai pengganti (mean/median). |
| **Interval / Rasio / Ordinal / Nominal** | Empat skala pengukuran (lihat notebook 01). |
| **IQR** | Q3 − Q1; lebar 50% data tengah. |
| **Kontingensi (tabel)** | Tabel silang jumlah dua variabel kategori. |
| **Korelasi (r)** | Kekuatan & arah hubungan linear, −1 s.d. +1. |
| **Levene** | Uji apakah varians antar kelompok sama. |
| **Median / Mean / Modus** | Nilai tengah / rata-rata / nilai paling sering. |
| **Multikolinearitas (VIF)** | Prediktor saling terlalu mirip; VIF besar = masalah. |
| **Normal (distribusi)** | Bentuk lonceng simetris, ditentukan μ dan σ. |
| **Outlier** | Nilai yang sangat jauh dari kebanyakan data. |
| **p-value** | Peluang mendapat hasil sekuat ini (atau lebih ekstrem) jika H0 benar. |
| **Peluang bersyarat P(A\|B)** | Peluang A jika B sudah terjadi. |
| **PM2.5** | Partikel udara berdiameter ≤ 2,5 mikrometer; makin tinggi makin buruk. |
| **Populasi / Sampel** | Semua yang ingin diteliti / bagian yang benar-benar diukur. |
| **Post-hoc Tukey** | Uji lanjut ANOVA: pasangan kelompok mana yang berbeda. |
| **Q-Q plot** | Grafik pembanding data dengan distribusi normal; titik lurus = mendekati normal. |
| **R²** | Proporsi variasi y yang dijelaskan model (0–1). |
| **Residual** | Selisih nilai asli dan prediksi model. |
| **Shapiro-Wilk** | Uji formal apakah data normal. |
| **Skewness** | Kemiringan distribusi (0 simetris; + ekor kanan; − ekor kiri). |
| **Skor Z** | (x − μ)/σ: jarak dari rata-rata dalam satuan simpangan baku. |
| **Standar deviasi / Varians** | Ukuran sebaran data / kuadratnya. |
| **Standard error (SE)** | Ketidakpastian suatu estimasi, s/√n untuk rata-rata. |
| **t-test (Student / Welch)** | Uji beda 2 rata-rata (varians sama / tidak sama). |
| **Winsorizing** | Memotong nilai ekstrem ke batas tertentu tanpa membuang baris. |
